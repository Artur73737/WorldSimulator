# Changelog

Tutti i cambiamenti rilevanti per questo progetto saranno documentati in questo file.

Il formato è basato su [Keep a Changelog](https://keepachangelog.com/it/1.0.0/)
e questo progetto aderisce alla [Versione Semantica](https://semver.org/lang/it/spec/v2.0.0.html).

## [1.0.1] - 2026-03-22

### Added
- Documentazione visiva avanzata con logo fotorealistico premium in formato PNG ad alta risoluzione.
- Design del logo 3D: Sfera di vetro traslucida con antiche rune in oro e flussi di dati digitali in azzurro neon.
- Ottimizzazione degli asset per garantire una visualizzazione perfetta e coerente su GitHub.
- Struttura README minimalista con sezioni interattive (accordions HTML).
- Integrazione di linee guida di design Apple-style per la documentazione.

### Changed
- Riorganizzazione della documentazione tecnica principale in sezioni esplorabili per migliorare la leggibilità.

## [1.0.0] - 2026-03-20

### Added
- Architettura iniziale del sistema World Simulation.
- Backend FastAPI con gestione cicli decennali e agenti LLM.
- Frontend React con visualizzazione grafo 3D tramite Three.js.
- Gestione delle fork simulazione basata su crisi sistemiche.
- Supporto per report storiografici automatici.
